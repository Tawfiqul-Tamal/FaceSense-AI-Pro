## Overview

FaceSense AI Pro is a professional desktop application developed using Python, PySide6, OpenCV, TensorFlow, and MediaPipe. The system performs real-time facial analysis through a webcam and provides intelligent insights including emotion recognition, age estimation, gender classification, attention monitoring, drowsiness detection, head pose estimation, blink counting, and data analytics.

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/FaceSense-AI-Pro.git
```

### Enter Project Directory

```bash
cd FaceSense-AI-Pro
```

### Install Required Packages

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```
